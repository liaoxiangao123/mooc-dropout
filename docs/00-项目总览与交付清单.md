## 六、端到端验证结果（合成数据，2026-10-22 训练 / 10-23 补充实验）

论文主结果使用**未校准**模型（与第 5 章各表一致）；服务部署使用**保序回归校准**版本，
两者产物已分开存档（`artifacts/model_uncalibrated/` 与 `artifacts/model/`）。

| 指标 | 主结果（未校准） | 部署版（E8 校准） |
|---|---|---|
| 数据 | 4000 条选课 / 208,381 条事件 / 辍学率 21.2% | 同左 |
| ROC-AUC | 0.729 | 0.736 |
| PR-AUC | 0.360 | 0.378 |
| 决策阈值 t* | 0.31 | 0.08（校准尺度重选） |
| Recall / Precision | 0.750 / 0.332 | 0.750 / 0.328 |
| 漏报 / 误报 | 41 / 248 | 41 / 252 |
| 人均期望代价 | ¥80.05 | ¥80.54 |
| Brier | 0.219 | **0.135** |

**结论要诚实说**：这套数字证明的是**链路跑通**，不是方法优越。合成数据区分度弱（AUC≈0.73），代价曲面平坦，各模型差异在噪声范围内。补充实验（E6~E8）已把「噪声范围」量化出来：五个随机种子的人均代价标准差为 4.7~5.4 元，而四个配置的均值极差仅 4.46 元；配对 Bootstrap 的四组比较区间全部跨零。详见 `reports/补充实验-多种子与校准.md`。

校准带来的直接收益是 **Brier 0.219 → 0.135（降 38%）**、人均代价仅上升 0.49 元（在噪声内），
而服务层现在输出的 `risk_probability` 是**可直接按字面理解的后验概率** —— 这一点对教师端至关重要。

可写进论文的观察：

1. 固定 0.5 阈值会让代价相差近一倍，但**阈值移动改变的是覆盖谁，而非花多少钱**——代价最优阈值与 0.5 的人均代价只差 0.12 元（区间跨零），召回率却相差 5.5 个百分点；
2. 类别加权会破坏概率校准（五种子 Brier 0.208 vs 0.137，ECE 0.227），保序回归校准可把 ECE 降到 0.025、人均代价几乎不变，但**校准后必须重选阈值**，否则沿用 0.5 会使代价上升 69%；
3. 代价比 ρ 从 1 升到 20 时 Recall 由 0.61 单调升到 1.00，预警规模可调可控；
4. 校准后的最优阈值（0.088）与 Elkan 解析阈值（0.0909）几乎重合，为 4.4 节的等价性推导提供了实证印证；
5. **超参搜索没有兑现**：OOF 上人均代价降 7.7%（74.58→68.85），但测试集上反而贵 1.95 元、区间 [−8.76, 11.80] 跨零。原因是 OOF 被反复用于选参、代价曲面平坦、瓶颈在特征可分性而非超参（论文 5.9.4）。这个否定结果与 5.8 的结论同源，反而强化了「决策链路优于模型」的立论。

## 八、真实数据复核（2026-10-23，KDD Cup 2015 官方训练集）

数据：120,542 条选课 / 8,157,277 条行为事件 / 39 门课程 / 79,186 名学习者 / 278 天，**辍学率 79.29%**。
两个标签口径各训一次，指标口径与合成数据完全一致（OOF 选阈值、测试集评估、保序回归校准）。

> **读表须知**：本节是 5.9.1 的主实验（`train.py`，250 轮 + 保序回归校准），而 5.9.6/5.9.7 的对比实验是
> 300 轮、3 折 OOF、**未校准**（`run_experiments.py`、`multiseed_realdata.py`）。协议不同，同一模型的
> 人均代价会差 0.1~0.4 元：CatBoost（代价敏感）在本节是 ¥20.54，在表 5-18 是 ¥20.58、表 5-20 的 5 种子均值是 ¥20.44。
> **三处数字不矛盾，是三次不同协议下的运行**；引用时请连同协议一起引。

| 项目 | 官方 dropout | 早期辍学（14 天） |
|---|---|---|
| 正类比例 | 79.29% | 67.63% |
| 样本（训练+测试） | 120,541 | 68,097 |
| ROC-AUC | 0.8407 | 0.8672 |
| PR-AUC | 0.9378 | 0.9121 |
| 阈值 / 预警比例 | 0.1048 / 98.88% | 0.0908 / 95.23% |
| 召回 / 精确率 | 0.9988 / 0.8016 | 0.9971 / 0.7109 |
| 人均代价 | ¥20.54 | ¥29.51 |
| 平凡基线（全报警） | ¥20.65 | ¥32.10 |
| **相对下降** | **+0.55%** | **+8.07%** |
| Brier（校准前→后） | 0.1581 → 0.1097 | 0.1923 → 0.1262 |

**核心发现（论文 5.9 节）**：ρ=10 时 Elkan 阈值 0.0909，而 79.29% 的基率使几乎所有校准概率都在
阈值之上，代价最优决策退化为「全部预警」，模型相对平凡基线只省 0.55%。这不是模型的错——
退化条件是 `F(p*) ≈ 0`，而基率高只是让它更容易发生。

两套补救工具（均已实现）：

1. **代价比扫描**（`scripts/cost_ratio_scan.py`，E11）：固定 C_FP=100 扫 ρ，用 OOF 重选阈值、
   测试集评估，无需重训。官方口径 ρ=1 时相对下降 **29.2%**，ρ=3 时 9.4%，ρ=10 时 0.55%，
   ρ=50 时退化为 0（预警比例 99.96%）。
2. **容量分析**（`scripts/capacity_analysis.py` + `evaluation/capacity.py`，E12）：把规则换成
   「只能干预 K 人，按风险排序取前 K」，以随机挑人为同容量基线。K=70% 时官方口径人均代价
   153.99 元 vs 随机 252.49 元（**−39.0%**），名单命中率 92.1%（基率 79.3%）；早期辍学口径
   86.48 vs 226.17 元（**−61.8%**），命中率 86.0%（基率 67.9%）。想抓 80% 辍学生，两个口径都
   需要覆盖 70% 的名单。

**五基线横向对比（论文 5.9.6、表 5-18/5-19、图 5-8）**：在两种标签口径上各跑一遍
LR / RF / HGBDT / CatBoost（无代价）/ CatBoost（代价敏感），共享同一特征矩阵与切分。

| 口径 | ROC-AUC 区间 | 人均代价区间 | 全报警基线 | 相对下降区间 | 预警比例 |
|---|---|---|---|---|---|
| 官方 dropout（n=23,934） | 0.8305~0.8433 | ¥20.52~20.72 | ¥20.65 | −0.30%~+0.65% | 98.4%~99.6% |
| 早期辍学（n=13,623） | 0.8586~0.8695 | ¥29.12~31.09 | ¥32.10 | +3.13%~+9.28% | 92.1%~94.9% |

三点值得记住：**（a）** 官方口径下五个模型的代价挤在 0.20 元区间内且贴着全报警基线，
差异消失的原因是决策规则退化，而非抽样误差（预警比例 98.4%~99.6%）；**（b）** RF 在
官方口径下比全报警更贵（20.72 > 20.65），说明退化区里「更精细的阈值」可能更糟；
**（c）** 代价敏感加权在两个口径上都没有增益（差 0.02 与 0.05 元），却把 Brier 从
0.1098 恶化到 0.1600 —— 正类已是多数类时，给正类加权的全部效果就是校准损失。

**多种子重复（论文 5.9.7、表 5-20/5-21、图 5-9，E14）**：5 种子（42/7/2024/1234/3407）× 4 配置
（CatBoost 代价敏感 / 无代价、HGBDT、LR）× 2 口径 = 40 次训练、160 次拟合，同一 seed 内四配置共享
切分与测试集（配对前提），seed=42 即 5.9.6 那次切分（可逐项复核）。

| 口径 | 配置间均值极差 | 单配置跨种子标准差 | 唯一不跨零的配对比较 |
|---|---|---|---|
| 官方 | 0.17 元 | 0.15~0.30 元 | 代价敏感 − LR = −0.17 元 [−0.30, −0.05]，5/5 |
| 早期 | 0.90 元 | 0.36~0.62 元 | 代价敏感 − LR = −0.89 元 [−0.97, −0.80]，5/5 |

三点结论：**（a）** 配置间极差（0.17 元）小于种子波动（0.15~0.30 元），连全报警基线本身都随切分
漂移 0.49 元，「A 比 B 便宜 0.05 元」在真实数据上没有统计依据；**（b）** 六组配对比较中只有
「代价敏感 vs LR」两个区间不跨零，与无代价版、HGBDT 的比较全部跨零，所以只能说「比 LR 略便宜」；
**（c）** 40 次运行的预警比例全部 ≥92.1%（官方全部 ≥98.4%），退化是结构性事实而非某次切分的偶然。

**在真实数据上重跑超参搜索（论文 5.10.5、表 5-23/5-24，E15 / E15b）**：协议与合成数据的 E9 完全相同
——3 折分组 OOF 上最小化人均期望代价，测试集全程不参与；TPE + MedianPruner，20 个 trial（12 完成、
8 剪枝），训练 96,608 条 / 测试 23,934 条。

| 阶段 | 配置 | OOF 人均代价 | 相对平凡基线 | 预警率 | ROC-AUC | 阈值 |
|---|---|---|---|---|---|---|
| OOF | 默认 400/6/0.05 | 20.34 | +1.84% | 98.89% | 0.8386 | 0.395 |
| OOF | 调参后（trial 3） | **20.23** | +2.36% | 99.00% | 0.8382 | 0.514 |
| 测试集 | 默认 | 20.44 | — | 98.87% | 0.8406 | 0.395 |
| 测试集 | 调参后 | **20.34** | — | 99.00% | 0.8389 | 0.514 |

三点结论：**（a）** OOF 只降 0.11 元（0.5%，合成数据是 −7.7%），因为预警率已达 98.89%，
相对平凡基线总共只有 1.84%（约 0.37 元）的空间可分配；**（b）** 测试集上低 0.10 元，配对 Bootstrap
区间 [−0.40, 0.16] 跨零，而这份测试集的分辨率（区间半宽）是 0.28 元 —— 收益落在噪声内；**（c）**
调参后 AUC 与 Brier 反而略差（0.8406→0.8389、0.1594→0.1624），便宜 0.10 元纯粹是阈值从 0.395
移到 0.514 带来的工作点偶然。**在退化区用代价调参等于在没刻度的尺子上测量**，8 个 trial 被剪枝
也不是「更差」，而是中位数剪枝在平坦目标面上等价于随机截断。

**顺带修掉的两个问题**：

- **LR 基线未收敛**：`max_iter` 原先硬编码 2000，而 lbfgs 在真实数据上需 5,667 次（官方）/ 4,432 次
  （早期）才收敛，`ConvergenceWarning` 被日志淹没。现改为可配置（默认 10,000），训练后核对
  `n_iter_ < max_iter` 并把 `n_iter`/`converged` 写进 `exp_comparison.csv`。修正后 LR 官方 AUC
  0.8375→0.8377、代价 20.52→20.59 元，早期 0.8654→0.8655、29.99→30.12 元，其余四个模型逐位不变。
- **调参脚本的两个隐患**：K 折特征原先在每个 trial 内重算（真实数据要重扫 815 万条事件 ×3 折 ×20
  trial），改为整轮只算一次、所有 trial 复用；OOF 位置原先按选课表行序回填，在字符串 ID 上会与标签
  错位，改为由 `X_train.index` 决定下标并对长度不一致直接抛错。

顺带修掉两个 bug（论文 5.9.3 有完整叙述）：

- **OOF 与标签错位**（严重）：ID 非补零时字典序 ≠ 行序，OOF 按行号回填导致阈值搜索在乱标签上
  运行，症状是「OOF AUC 0.51 / 测试集 0.82、阈值恒为 0.01」。已在 `trainer.py` 改为按 ID reindex
  并加回归测试。**合成数据 ID 等宽补零，这个 bug 在合成数据上永远测不出来。**
- **阈值网格分辨率不足**：`linspace(0.01,0.99,99)` 会把最优解卡在 0.01 边界。已改为排序 + 前缀和的
  精确搜索（O(n log n)）。
