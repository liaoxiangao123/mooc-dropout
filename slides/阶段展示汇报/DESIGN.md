## 全局视觉约定

### ① 画布与安全区
- 画布 1280×720（16:9，输出 12192000×6858000 EMU）
- 内容页：顶条 76px（含主标题），主体区 x=100–1180，页脚/结论条至 y=660
- 封面不受顶条与页脚约束

### ② 配色（学术宝蓝 + 白底）

| 槽位 | Hex | 用途 |
|---|---|---|
| 主色 | `#1E4FA8` | 顶条、结论条、关键数字、编号块 |
| 辅色 | `#3D7BD9` / `#8FA8C9` | 序号、次级数字、箭头 |
| 浅底 | `#E8EFF8` / `#F7F9FC` | 结论条 / 卡片底 |
| 强调色 | `#D9534F` | **全篇仅 1 处**：P5 的 98.9%（决策退化的症状） |
| 正文色 | `#1A2230` / `#4A5568` / `#8B97A8` | 主 / 副 / 辅助 |
| 分隔线 | `#E5E7EB` / `#D6DCE5` | 1px |

纪律：蓝族 20–40%；红仅 1 处；不用金色；不用大色块铺底（P6 结尾条为唯一满色块，用于收束）。

### ③ 字体
- 中文：思源黑体 / 系统无衬线，全篇单一字族，靠字重拉层级
- 字号阶梯：封面主标 62 / 封面副标 22 / 顶条主标题 34 / 区块标题 20 / 正文 16–19 / 图注 13 / 页脚 13 / KPI 34–58 / 巨数字 104
- 数学符号用 Unicode 直接排版（η、ρ、→、×），分式用「上 / 1px 横线 / 下」三段 Box 叠出，**不用 `<Math>`**（MathJax 在本地转换器内渲染为空）

### ④ 视觉母题
- 内容页统一「深蓝顶条 + 右侧 `0X / 06` + 1px 分隔线 + 底部浅蓝结论条」
- P1 封面：左侧 5px 深蓝竖线 + 62px 主标，无顶条无页脚
- P6 结尾：结论条改为深蓝满色（白字），作为全篇唯一的重色块收尾

## 口径纪律（讲之前必须清楚）

1. **P4 不能把 76.64 / 77.13 与 80.41 并列**。前者来自 E2 配置（250 轮、3 折 OOF），后者来自主模型（400 轮、5 折 OOF），论文 5.2 节已声明不可直接比对。P4 因此改用「召回率 / 阈值 / 预警人数」三项无量纲指标证明等价性，代价只在 80.05 与 80.41 之间比较。
2. **75.91 元不是成绩**。它是事后在测试集上挑的最低点，属泄漏；报告的是 OOF 选阈的 80.41。图上两者分开标注。
3. **P5 的 39.0% / 92.1% 是容量规则（前 70%）的指标**，不是阈值规则的指标，不能与 0.55% 混谈。
